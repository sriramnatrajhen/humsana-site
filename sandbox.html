See a refusal on a live action.

The sandbox runs one action class against the live service with synthetic data: an approved payout release. Change the destination account, and the executor asks Humsana whether the action is still the one that was approved. It is not, so the service refuses it.

Open the sandboxHow it works

Four values, four outcomes.

The approved action is a payout release: £1,800 to Supplier X, account 4821, valid until 14:00.

Change the account to 9137 and press Execute.

Change the amount, the beneficiary, the account or the expiry.

Restore the approved value and the same action is allowed, once.

What the sandbox is.

No account and no login. Synthetic data only, and no money moves. A run keeps its own state for a short time, so a reload keeps it.

Where a confirmation is shown, the sandbox uses a reference confirmer and labels it.

Reference confirmer, demo only. The five-step run by command, with the record checked offline, is on the walkthrough.
