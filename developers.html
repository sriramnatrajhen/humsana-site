01The problem

The worst mistakes are not random.

They happen when you are sleep-deprived, overloaded, or rushing late at night. AI cannot see that, so it executes destructive commands and overwrites files with false confidence anyway.

01

Observe timing

A local daemon monitors typing rhythm, corrections, and activity. Never content.

02

Analyze on-device

Stress, focus, and fatigue are computed on your machine. No cloud required.

03

Gate unsafe actions

Destructive operations are blocked when fatigue is high. Overrides are logged to an audit trail.

02MCP tools

What Claude and other agents receive.

get_user_state

Stress, focus, and fatigue levels, plus response-style recommendations.

check_dangerous_command

Whether a command is dangerous and fatigue exceeds threshold.

safe_execute_command

Runs shell commands with interlock protection. Blocks when fatigued.

safe_write_file

Blocks large destructive rewrites when the user is fatigued.

Blocked when fatigue is high: rm -rf, DROP TABLE, git push --force, kubectl delete, terraform destroy. Override with OVERRIDE SAFETY PROTOCOL: [reason], logged to ~/.humsana/audit.log.
